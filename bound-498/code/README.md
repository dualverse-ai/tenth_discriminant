# Numerical calculations

These Python programs reproduce the finite comparisons and the large-discriminant estimates in the paper. They require Python 3; the divided-Frobenius calculation also lists its dependencies in `paper22/requirements.txt`. Run the programs from this directory. For example:

```sh
python summarize.py
python run_baseline.py
python run_candidates.py 312000000 523 547
python simplified_rank.py
```

The source files and numerical inputs used by the calculations are kept in this directory.
